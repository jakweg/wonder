# Wonder `.2bc.json` Enum Compiler

## Key Files

- **Compiler:** `encytem/src/build/compile-enums.ts` (uses only Node built-ins `child_process` & `fs/promises`; baked into Docker image by `encytem/compiler.Dockerfile`)
- **Schema:** `barbet/enum-schema.json` (mapped to `**/*.2bc.json` in `.vscode/settings.json`; do not add `"$schema"` inside `.2bc.json` files)
- **Prod mangling allowlist:** `barbet/src/build/exclude-from-mangling.txt`
- **Examples:**
  - `barbet/src/main/game-state/world/block.2bc.json` -> `block.ts` (`add-size`, `convert-hex-colors`)
  - `barbet/src/main/game-state/new-entities/kind.2bc.json` -> `kind.ts` (`#comment`, `@store` array, `reverse-mapping`, `all-values`)
  - `barbet/src/main/game-state/new-entities/activities/activities.2bc.json` -> `index.ts` (`#Group` + `import-prefix`)
  - `barbet/src/main/3d-stuff/model/model-id.2bc.json` -> `model-id.ts` (`#Group` with `"from": ""`)
  - `barbet/src/main/3d-stuff/model/builder/model-attribute-type.2bc.json` -> `model-attribute-type.ts` (dotted `property`, e.g. `"AttrType.UByte"`)

## `.2bc.json` Format Reference

Top-level object (`additionalProperties: false`):

- `name` _(string, required)_: Name of emitted `export const enum <name>`.
- `output-file` _(string, optional)_: Output `.ts` basename in same directory (defaults to filename before first `.`).
- `add-size` _(boolean, optional)_: Appends `SIZE,` as final enum member.
- `values` _(object, required)_: Enum entries in declaration order (`0, 1, ...`). **Never reorder** persisted/serialized enums (e.g. `BlockId`).
  - **Flat entry** `"Member": { ... }`:
    - `"#comment"`: Emits `/** ... */` JSDoc above member.
    - Primitive field `"key": string | number | boolean`.
    - Import field `"@key"`: Single import object or array of import objects (**arrays only support import objects, not primitives**):
      - `{ "from": "./mod", "property": "fn" }` -> `import * as <alias> from './mod'` and emits `<alias>.fn` (`property` supports dotted paths like `"AttrType.UByte"`; `property: null` or `""` imports default).
      - `{ "default-from": "./mod" }` -> `import <alias> from './mod'` and emits `<alias>`.
      - Duplicate import paths are deduplicated per output file.
  - **Grouped entry** `"#Prefix": { "import-prefix": "./dir/", "values": { "Child": { ... } } }`:
    - Emits `Prefix_Child` and prepends `import-prefix` to `from`/`default-from`. (`#comment` is not currently emitted inside `#` groups.)
- `getters` _(object, optional, `additionalProperties: false`)_:
  - `field` _(string, required)_: Reads `entry[field] ?? entry["@" + field]` (`@` prefix optional).
  - `type` _(optional, default `"getter"`)_:
    - `"getter"`: `(value: <Enum>) => ...` via `switch (value)`.
    - `"reverse-mapping"`: `(value: unknown) => <Enum>[]` inverting field values (including array items) back to matching enum members.
    - `"all-values"`: `() => [...]` returning unique values deduplicated via `Set<string>`.
  - `if-invalid-enum` _(optional, default `"throw"`)_: `"throw"` | `"return-null"` | `"return-undefined"` (ignored for `"all-values"`).
  - `convert-hex-colors` _(boolean, optional)_: Validates `/^#[0-9a-fA-F]{6}$/` strings and emits lowercase `0xrrggbb` integer literals (works with all getter types; throws at compile time on invalid values).

## Compiling `.2bc.json`

`compile-enums.ts` runs natively on **Node 24+** (type-stripping; check `~/.nvm/versions/node/v24*/bin/node` if default `node` is v20) with no `node_modules` required.

### Pitfall: Avoid Clobbering Prettier Formatting on Other Files

`compile-enums.ts` scans **all** `src/**/*.2bc.json` under `cwd` and invokes `npx --no-install prettier --write <file>`, silently ignoring errors if Prettier is missing. Running it directly in `barbet/` without Prettier locally installed overwrites all generated `.ts` files with single-line unformatted output.

- **If Prettier is installed locally (or inside Docker):**
  ```bash
  cd barbet && node ../encytem/src/build/compile-enums.ts
  ```
- **If Prettier is NOT installed locally (single-file isolated compile from repo root):**
  ```bash
  COMPILER="$PWD/encytem/src/build/compile-enums.ts"
  rm -rf /tmp/compile-2bc && mkdir -p /tmp/compile-2bc/src && \
  cp barbet/src/path/to/file.2bc.json /tmp/compile-2bc/src/ && \
  (cd /tmp/compile-2bc && ~/.nvm/versions/node/v24.19.0/bin/node "$COMPILER")
  ```
  Inspect `/tmp/compile-2bc/src/<output-file>.ts`, write the target `.ts` formatted to match existing generated files (keeping the exact autogenerated header and `/* This function was autogenerated, don't change */` comments), and delete `/tmp/compile-2bc`.

## Pitfalls & Verification

1. **Do NOT use `"type": "all-values"` for enum-indexed tables** (e.g., shader lookup arrays): `Set` deduplication collapses duplicate values and shifts indices. Use `"add-size": true` and iterate `for (let id = 0; id < Enum.SIZE; id++)` calling the getter.
2. **Keep schema and compiler in sync:** Whenever adding a new `.2bc.json` option in `encytem/src/build/compile-enums.ts`, add it to `barbet/enum-schema.json` too.
3. **Docker `dev-compiler` rebuild:** `encytem/compiler.Dockerfile` bakes `compile-enums.ts` at image build time — remind the user to rebuild the container after modifying `compile-enums.ts`.
4. **Prod property mangling:** `encytem/src/build/index.ts` runs esbuild with `mangleProps: /./` using `barbet/src/build/exclude-from-mangling.txt`. Avoid unlisted built-in properties in callers (e.g., do not use `Array.from`; use plain loops or allowlisted methods/bracket notation).
5. **Verify:** Run `cd barbet && npx --yes -p typescript tsc --noEmit` and check `git status` to ensure no unrelated generated `.ts` files were reformatted.
